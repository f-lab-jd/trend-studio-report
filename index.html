생성 모델 열어두기

생성 모델을 코드에 고정하지 않고 데이터 파일로 바꿨습니다. 밈에 쓰인 새 모델은 data/engines/<id>.json 파일 하나로 추가됩니다. 구매자 화면에는 모델 선택이 없고, 템플릿이 어떤 모델로 만들지를 정합니다.

스카우트가 밈을 만든 모델을 트렌드 스펙의 target.engine에 적으면 공장은 그 모델로 초안을 만듭니다. 카탈로그에 없는 모델이면 engine_unknown, 해당 트렌드를 만들 수 없는 모델이면 engine_unfit으로 돌려보냅니다.

엔진 파일 하나에 담기는 것:

  • fal 엔드포인트와 요청 본문 틀. $prompt·$image 같은 자리표시자를 장면마다 채웁니다.
  • 초당 또는 클립당 가격. 원가 35% 상한과 하루 지출 한도에 그대로 쓰입니다.
  • 장면 길이 범위(6초·10초처럼 정해진 값도 가능)와 최대 장면 수.
  • 얼굴 고정 방식(Kling의 @Element1)과 결과에서 영상 주소를 읽는 위치.
  • 밈별로 바꿀 수 있는 설정(스타일·효과). 가격과 해상도는 바꿀 수 없습니다.

파일에 오타가 있거나 9:16 비율이 빠지면 테스트가 실패해서 배포되지 않습니다. 새 모델로 만든 템플릿은 실제 테스트 주문을 통과해야 판매됩니다. 지금 등록된 모델은 PixVerse v5.5(기존 5초)·v6, Kling v3 Standard입니다.

결제사 상품 추가 결과

상품은 아직 만들지 못했습니다. Dodo와 Polar 모두 로그인 화면이 떠 있었고, 계정 가입과 로그인은 본인이 직접 해야 하는 단계입니다. 로그인만 되면 상품 생성과 Vercel 연결은 화면을 조작해서 끝까지 진행합니다.

첫 상품은 지금 판매 중인 템플릿 4개가 쓰는 단품입니다. 이 하나만 있어도 테스트 모드에서 결제부터 영상 전달까지 전 과정을 돌려 볼 수 있습니다.

Vercel 무료 플랜 대응

무료(Hobby) 플랜에 맞춰 10분 간격 크론은 등록하지 않았습니다. 장면은 fal 완료 알림으로 바로 이어집니다. 알림이 빠지면 주문 페이지를 열 때와 하루 1회 크론(03:00 UTC)이 멈춘 작업을 다시 진행합니다. 테스트와 출시 전 점검에는 충분합니다.

첫 실결제 전에는 Pro($20/월)로 올려야 합니다. Vercel 정책상 Hobby는 비상업적 개인 용도로만 쓸 수 있고, 방문자에게 결제를 받는 사이트는 상업적 이용입니다(공정 사용 가이드).

Hobby의 Active CPU는 월 4시간입니다. 영상 1초 처리에 약 1초가 걸리므로 30초 영상 기준 한 달 수백 건이 상한입니다.

Pro로 올리면 10분 크론을 켜서 장애 복구 시간도 하루에서 10분으로 줄입니다.

해주셔야 할 일

제가 대신할 수 없는 것은 계정 가입·로그인과 비밀 키 입력뿐입니다. 나머지는 로그인된 화면이 있으면 제가 진행합니다.

  1. 1이 Chrome에서 Dodo(app.dodopayments.com)에 가입·로그인하고 테스트 모드로 전환. 그다음에는 제가 단품 상품을 만들고 Vercel에 연결합니다.
  2. 2Dodo 테스트 API 키·웹훅 시크릿과 PAYMENT_PROVIDER=dodo를 Vercel 환경변수에 입력
  3. 3fal.ai에 가입·로그인하고 FAL_KEY와 FAL_DAILY_CAP_USD(예: 20)를 Vercel에 입력. 그다음에는 제가 엔진별 실제 생성 테스트를 돌리고 초안 3개를 판매로 올립니다.
  4. 4ANTHROPIC_API_KEY를 Production에 입력(텍스트 템플릿 검수용)
  5. 5Resend에 가입하고 RESEND_API_KEY·EMAIL_FROM·ALERT_EMAIL 입력
  6. 6자체 도메인 구매. 연결과 Dodo Product Information Form 초안은 제가 준비합니다.
  7. 7첫 실결제 전에 Vercel Pro로 전환
  8. 8메일 초안 3개 발송 여부 결정
